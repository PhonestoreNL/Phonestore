# PhoneStore website

Dit is een gewone informatieve website voor PhoneStore BV. Er zit bewust **geen webshop** in: geen winkelmand, geen bestellen en geen online betaalfunctie.

## Publiceren met GitHub Pages
1. Maak op GitHub een nieuwe repository, bijvoorbeeld `phonestore-website`.
2. Upload `index.html`, `style.css` en `script.js`.
3. Ga naar **Settings → Pages**.
4. Kies **Deploy from a branch** en daarna de hoofdbranch (`main`).
5. GitHub geeft daarna de website-link.

## Belangrijk
De Instagram- en TikTok-accounts zijn niet ingevuld, omdat de exacte accountnamen/links niet in de aangeleverde informatie stonden. Zo wordt er geen informatie verzonnen.
